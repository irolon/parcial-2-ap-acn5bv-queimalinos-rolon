# Usuarios objetivo (Personas)

Perfiles de usuario que guían las decisiones de diseño y priorización.

> **Nota sobre plataformas:** ambos roles (entrenador y alumno) pueden acceder a FitTrainer indistintamente desde la web o desde la app móvil. Lo que se describe abajo como "uso típico" no implica exclusividad sino el patrón más probable según el contexto del usuario.

---

## Marcos Villalba — Personal Trainer independiente (Buyer Persona principal)

| Campo | Detalle |
|---|---|
| Edad | 28 años |
| Ocupación | Personal trainer independiente, recibido hace 4 años. Profesor de Educación Física. |
| Ubicación | CABA, zona Caballito / Almagro |
| Ingreso mensual | Variable, alrededor de AR$ 900.000. |
| Modalidad de trabajo | Trabaja en un gimnasio (alquilando turno) y hace clases en plaza Las Heras. Además entrena personas a distancia. Tiene aproximadamente 20 alumnos activos. |
| Herramientas actuales | WhatsApp para comunicarse, Excel/Google Sheets/Word/PDF para armar las rutinas, Notas del celular para anotar cargas, Mercado Pago para cobrar. |
| Nivel tecnológico | Medio. Usa apps cotidianas (Instagram, WhatsApp, Mercado Pago, MercadoLibre) pero no es power user de software profesional. |
| Uso típico de FitTrainer | Web desde su PC para armar rutinas con el asistente IA, gestionar alumnos y revisar el dashboard de seguimiento. Mobile en el gym o en la calle para responder mensajes, ver alertas de inactividad, dejar comentarios en las sesiones recientes de sus alumnos y consultar rápidamente datos puntuales. |
| Objetivos | Crecer su cartera de clientes. Diferenciarse y poder cobrar un poco más por sesión. Profesionalizar su marca. Tener más tiempo disponible para atender a más clientes. Ofrecer un servicio más profesional, personalizado y una mejor experiencia. |
| Frustraciones | Gastar horas armando rutinas. No saber con certeza si el alumno cumple la rutina. Que las apps profesionales del rubro estén en inglés y se paguen en USD. No poder ver la información de forma centralizada. No poder seguir claramente el progreso de cada cliente. |
| Cita representativa | "Yo quiero entrenar gente, no perder tiempo armando planillas. Y los alumnos cada vez quieren cosas más específicas para sus necesidades, no se puede seguir mandando PDFs por WhatsApp." |

**Dolor principal:** pierde tiempo armando rutinas manualmente, mandando PDFs por WhatsApp y haciendo seguimiento improvisado. Quiere una herramienta donde tenga todo centralizado y que la IA le acelere el armado de plantillas, y poder consultarla tanto desde su PC como desde el celular cuando está fuera de su casa.

**Motivación:** diferenciarse de otros PTs, dar una experiencia más profesional a sus alumnos y poder atender más gente sin sacrificar calidad.

## Laura Castillo — PT online

| Campo | Detalle |
|---|---|
| Edad | 34 años |
| Modalidad | Clases por Zoom, alumnos remotos |
| Alumnos activos | ~15 |
| Perfil | Muy técnica, orientada a resultados |
| Uso típico de FitTrainer | Web como herramienta principal de trabajo (armado de rutinas, dashboard, mensajería). Mobile para responder rápido cuando está fuera del estudio. |

**Dolor principal:** no puede ver si sus alumnos realmente hacen las rutinas como indicó ni cuánto cargan. Necesita el historial de cargas y poder dejar feedback por sesión sin estar físicamente presente.

**Motivación:** poder cobrar más (y justificarlo) por un servicio más profesional, medible y con seguimiento real. Que el asistente IA del alumno descomprima sus consultas a distancia.

## Tomás García — Alumno (objetivo: ganar masa muscular)

| Campo | Detalle |
|---|---|
| Edad | 24 años |
| Frecuencia | 4 días/semana |
| Perfil | Nativo digital, no quiere perder tiempo en apps |
| Uso típico de FitTrainer | Mobile como herramienta principal (rutina del día, registro de series, asistente IA en sesión). Web ocasionalmente desde la PC para revisar su historial de progreso con más detalle, ver gráficos en pantalla grande o leer comentarios del entrenador. |

**Dolor principal:** usa papel para anotar pesos, se le pierde o se mancha. Quiere algo rápido — durante el gym no quiere perder tiempo en la app.

**Motivación:** ver su progreso visualmente, que la app le sugiera la carga del día siguiente, y desbloquear logros y rachas que lo mantengan motivado.

## Sofía Ramos — Alumna (objetivo: bajar de peso)

| Campo | Detalle |
|---|---|
| Edad | 38 años |
| Frecuencia | 3 días/semana |
| Perfil | No tech-savvy, motivación variable |
| Uso típico de FitTrainer | Mobile en el gym. Web desde la notebook de su casa para ver con calma su progreso, las medidas corporales y los desafíos asignados por la entrenadora. |

**Dolor principal:** se olvida los ejercicios que le mandó el PT, necesita ver el video de cada uno. Le cuesta la adherencia a un plan a largo plazo.

**Motivación:** ver gráficos de progreso, recibir mensajes del PT que la alienten a seguir, y desbloquear desafíos y rachas que le den un motivo extra para volver al día siguiente.
